# Release notes — 1.2.2

iOS only. App Store Connect → version 1.2.2 → "What's New in This Version" (per
localization), TestFlight → "What to Test" (same text). Request an expedited
review: 1.2.1 crashes at launch on every iOS 27 device.

```
<ko-KR>

• iOS 27에서 앱이 실행되자마자 종료되던 문제를 고쳤어요.
</ko-KR>
<en-US>
What's new

• Fixed MIRI closing immediately on launch on iOS 27.
</en-US>
```

Expedited review reason (App Store Connect → Contact Us → Request Expedited App Review):

```
Version 1.2.1 crashes immediately at launch on every device running iOS 27, so
iOS 27 users cannot open the app or manage their alarms. Version 1.2.2 fixes the
crash (the app now adopts the UIScene life cycle required for apps built with the
iOS 27 SDK) and contains no other changes for users.
```
