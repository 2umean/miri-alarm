# Release notes — 1.2.0

App Store Connect → version 1.2.0 → "What's New in This Version" (per localization),
Google Play → Release → Release notes (paste the tagged block), TestFlight →
"What to Test" (same text).

```
<ko-KR>
이번 업데이트

• 스누즈가 생겼어요 — 알람이 울릴 때 "5분 뒤 다시 알림"을 누르면 5분 뒤에 같은 알람이 다시 울려요. 잠금화면 알람과 알림 모두에서 쓸 수 있어요.
• 다시 울릴 알람은 앱을 다시 열어도 그대로 유지돼요. 취소하려면 알람을 끄거나(중지) 홈에서 해제하세요.
</ko-KR>
<en-US>
What's new

• Snooze — tap "Snooze 5 min" on a ringing alarm and the same alarm rings again five minutes later, from the lock-screen alarm or from the notification.
• A pending snooze survives reopening the app; stop the alarm or disarm from Home to cancel it.
</en-US>
```
