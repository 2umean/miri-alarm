# Google Play release notes — 1.1.0

Copy-paste the whole block into Play Console → Release → Release notes:

```
<ko-KR>
이번 업데이트

• 일정 알림이 더 깔끔해졌어요 — 이제 어떤 일정이 끝났는지만 알려드려요. 중간 일정 알림에 "지금 나가면…" 같은 출발 안내가 붙지 않아요.
• 도착 시간 입력이 빨라졌어요 — 시를 다 입력하면 커서가 분으로 자동 이동해요. 3~9시는 한 자리만 눌러도 바로 넘어가요.
</ko-KR>
<en-US>
What's new

• Cleaner schedule alerts — notifications now simply say which event just ended, without departure wording on mid-schedule alerts.
• Faster arrival-time entry — finish typing the hour and the cursor hops to minutes automatically. Hours 3–9 jump after a single digit.
</en-US>
```

Same text works for TestFlight "What to Test".
