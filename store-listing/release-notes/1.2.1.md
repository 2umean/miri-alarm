# Release notes — 1.2.1

App Store Connect → version 1.2.1 → "What's New in This Version" (per localization),
Google Play → Release → Release notes (paste the tagged block), TestFlight →
"What to Test" (same text).

이번 업데이트

<en-US>
What's new

• You can now arm a schedule whose ⏰ alarm time has already passed, as long as a 🔔 notification is still ahead — MIRI tells you that only the remaining notifications will go off.
• A schedule armed this way stays armed when you reopen the app.
</en-US>
