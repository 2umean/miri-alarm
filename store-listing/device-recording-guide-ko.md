# MIRI Alarm — 심사용 화면 녹화 가이드 (친구용, 한국어)

친구에게 그대로 전달하는 원테이크 녹화 스크립트. Apple 2.1 Information Needed 회신용.
근거: 시드 체인의 ⏰ 알람은 도착 시각 − 75분(🚿20+🍳20+🚇35)에 울림 →
도착을 "지금+1시간 20분"으로 잡으면 Arm 후 약 5분 뒤 알람이 확실히 울림.
회신 문서는 `app-review-reply.md` — 친구 영상을 쓰면 시뮬레이터 각주 문장은 삭제하고
[iPhone model]/[iOS 26.x] 자리를 친구가 알려준 값으로 채울 것.

---

## 미리 알아둘 핵심 3가지

1. **설치 후 앱을 미리 열지 말기** — 첫 실행 팝업들이 영상에 꼭 담겨야 해요.
2. **녹화 중 폰을 잠그지 말기** — 잠그면 화면 기록이 끊길 수 있어요.
3. **도착 시간 = 지금 + 1시간 20분** — 그래야 5분 뒤 알람이 울려요.

## 1) 준비 — 녹화 전에 한 번만 (약 5분)

- [ ] iOS 버전 확인: 설정 > 일반 > 소프트웨어 업데이트 → **iOS 26 이상 + 최신 상태**로.
      (앱이 iOS 26 전용이라, 업데이트가 안 되는 기기면 나한테 먼저 알려줘!)
- [ ] App Store에서 **TestFlight** 설치 → 내가 보낸 초대 링크 수락 → **MIRI Alarm** 설치.
      ⚠️ 설치만 하고 앱은 아직 열지 말기!
- [ ] (권장) 앱 언어를 영어로: 설정 > 앱 > MIRI Alarm > 언어 > **English**.
      심사관이 읽기 편해져요. 폰 전체 언어는 안 바뀌어요.
- [ ] 제어 센터에 **화면 기록** 버튼 추가: 설정 > 제어 센터 > '화면 기록' ＋.
- [ ] 화면 기록 버튼을 **길게 눌러 마이크 켜기** (알람 소리가 영상에 담기게). 조용한 곳에서 찍기.
- [ ] 자동 잠금 끄기: 설정 > 디스플레이 및 밝기 > 자동 잠금 > **안 함**.
- [ ] **방해금지(집중 모드) 켜기** — 카톡 등 개인 알림이 영상에 찍히는 걸 막아줘요.
      (MIRI 알람은 방해금지를 뚫고 울리니 걱정 없음)
- [ ] 이 가이드는 **다른 기기(PC나 다른 폰)** 에서 보면서 진행하기.

## 2) 녹화 — 한 번에 쭉 (영상 약 7분)

1. 홈 화면에서 제어 센터 열고 **화면 기록 시작** → 홈 화면으로 나와 3초 대기.
2. **MIRI Alarm 실행.**
3. 팝업 ① 추적 허용(맞춤 광고) → **허용** 탭.
4. 온보딩에서 **Enable** 탭 → 팝업 ② 알람 권한 → **허용** → **Continue**.
   분석(analytics) 토글이 보이면 **건드리지 말고 그대로**(꺼짐이 기본) 진행.
5. 준비 단계 카드 하나(예: 🚿 Shower) 탭 → **이모지나 이름만** 살짝 바꾸고 저장.
   ⚠️ 시간(분)은 바꾸지 말기 — 알람 타이밍 계산이 틀어져요.
6. 주황색 **Arrive** 줄 탭 → 도착 시간을 **지금 + 1시간 20분**으로 입력.
   (예: 지금 2:00 → 3:20 / 밤 10시 40분 이후에 찍는다면 날짜를 내일로)
7. 설정하자마자 **1분 안에** **Arm alarm** 탭 → 팝업 ③ 알림 허용 → **허용**.
8. 이제 **약 5분 대기**. 기다리는 동안 화면의 알람 시각 목록을 천천히 보여주기.
   ⚠️ 폰 잠그지 말고 화면 켠 채로!
9. 알람이 울리면 **2~3초 울리게 둔 뒤** 중지(Stop) 탭.
10. 앱 메인 화면을 한 번 더 보여주고 → 제어 센터에서 **화면 기록 중지**.

## 3) 보내기 (약 2분)

- [ ] 사진 앱에서 영상 확인: **팝업 3개(추적/알람/알림) + 알람 울리는 장면**이 다 있는지.
- [ ] **원본 화질로** 보내기: 카톡은 '파일'로 첨부(일반 동영상 전송은 압축됨),
      또는 iCloud/Google Drive 링크.
- [ ] 같이 알려주기: **기기 모델명**(설정 > 일반 > 정보 > 모델 이름, 예: iPhone 15 Pro)
      + **iOS 버전**.

## 실수했을 때

앱 삭제 → TestFlight에서 재설치 → (앱 언어 다시 English로) → 녹화부터 다시.
권한 팝업들이 처음부터 다시 나와요.
